## Executar este projeto localmente

**Pré-requisito:** Node.js

1. Instale as dependências:
   `npm install`
2. Configure no arquivo `.env.local` as variáveis de ambiente exigidas pela aplicação.
3. Inicie o servidor de desenvolvimento:
   `npm run dev`
